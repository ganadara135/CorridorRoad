# Parametric Road 1.0.1 Forum Announcement Draft

Use this draft for the FreeCAD Forum `1.0.1` update announcement.

```markdown
Parametric Road 1.0.1 has been released.

The biggest visible change is the project name:

**Corridor Road is now Parametric Road.**

I changed the name because the project is no longer focused only on generating a road corridor surface. The goal is to build a broader parametric road-design workflow inside FreeCAD, including alignment, profile, stations, regions, structures, drainage, review tools, and eventually simulation-ready solid models.

In version 1.0.1, the documentation and workflow have been updated around this direction.

Main updates:

- Renamed the user-facing workbench/project name from **Corridor Road** to **Parametric Road**
- Updated README, Addon overview, Wiki draft pages, and release notes
- Added clearer workflow documentation for:
  - 3D Centerline
  - Regions
  - Structures
  - Drainage Flow Routes
  - Watertight Solids
- Improved the current v1 workflow description so Drainage is no longer presented as only a placeholder stage
- Added release preparation notes for the current development direction

I also prepared a tutorial video for this update:

https://youtu.be/_xpqwnXPUU8

The long-term goal is to make Parametric Road capable of producing road, drainage, and structure geometry that can be used directly for simulation. In other words, the final target is not only drawing or visual review, but creating structured, watertight solid models that can become practical simulation inputs.

Release:

https://github.com/ganadara135/CorridorRoad/releases/tag/v1.0.1

This is still an active v1 development stage, but version 1.0.1 is an important step toward that goal.
```
